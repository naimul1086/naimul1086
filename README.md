##  Featured Project

###  ShopEase — E-Commerce Android App  

> A scalable, production-ready e-commerce application built using modern Android architecture.

---

###  Tech Stack
- **Language:** Java  
- **Architecture:** MVVM + Clean Architecture  
- **Networking:** Retrofit2 (REST API - DummyJSON)  
- **Local Storage:** Room Database (Offline-first)  
- **Authentication:** Firebase Auth (Email + Google)  
- **Image Loading:** Glide  

---

###  Key Features
-  Secure user authentication with Firebase  
-  Dynamic product listing using RecyclerView + DiffUtil  
-  Offline-first experience with Room caching  
-  Real-time API integration with error handling  
-  Smooth UI performance and optimized data flow  

---

###  Highlights
- 📌 Implemented **Repository Pattern** for clean data handling  
- 📌 Separation of concerns using **MVVM layers**  
- 📌 Efficient UI updates with **DiffUtil**  
- 📌 Scalable and maintainable codebase
